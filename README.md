# 🏆 大乐透预测工具

基于历史数据分析的多维度条件筛选工具，纯前端运行，无需后端服务器。

## ✨ 功能特性

- **📊 最近10期开奖号码**：自动从体彩官方接口获取最新开奖数据并展示
- **🎚️ 过滤预设**：保存 / 加载 / 删除当前筛选条件组合，方便复用
- **三个预测标签页**：

| 标签页 | 玩法 | 过滤面板 |
|--------|------|----------|
| 🎯 前五红球 | 前区 5 位红球 | ① 位置号码过滤 · ② 二位和/差过滤 · ③ 高级过滤 |
| 🎯 前六红球 | 前区 6 位红球 | ① 位置号码过滤 · ② 二位和/差过滤 · ③ 高级过滤 |
| 🔵 后区蓝球 | 后区 2 位蓝球 | ① 位置号码过滤 · ② 综合过滤 · ③ 比值过滤 |

- **多维过滤条件**：
  - 位置号码过滤（按位置指定号码）
  - 二位和值 / 差值过滤
  - 高级过滤：位置交集、质合 / 奇偶、综合值
  - 比值过滤：质合比、奇偶比、大小比、大中小比、路比
  - 复隔中 · 冷热温 · 孤邻串
  - 奇数 / 偶数 / 质数 / 合数和值
  - 尾数组合 · AC 值 · 平均值 · 尾数和 · 尾数个数
- **⬇️ 导出结果**：一键导出为 Excel（`.xlsx`）文件
- **🔍 开始预测**：应用全部筛选条件生成预测号码

## 🖥️ 本地使用

方式一：直接双击打开 `index.html`

方式二：本地启动静态服务器

```bash
# 任意静态服务器均可，例如 Python
python3 -m http.server 8080
# 然后浏览器访问 http://localhost:8080
```

## 📡 数据来源

开奖数据按以下优先级获取：

1. **体彩官方接口**（首选）：`webapi.sporttery.cn` 大乐透历史开奖数据
2. **备用数据源**：GitHub 上维护的大乐透开奖数据 JSON 文件
3. **内置兜底数据**：接口不可用时回退到内置的最近 10 期真实开奖数据

> ⚠️ 说明：直接以 `file://` 方式打开时，浏览器安全策略会限制跨域请求，此时会使用内置兜底数据；部署到服务器或本地静态服务器后可正常获取官方接口数据。

## 🛠️ 技术栈

- 纯原生 HTML + CSS + JavaScript，无任何构建步骤
- [SheetJS (xlsx)](https://cdn.jsdelivr.net/npm/xlsx@0.18.5/dist/xlsx.full.min.js) 用于导出 Excel（CDN 加载）
- 开奖数据通过 `fetch` 从公开接口获取
